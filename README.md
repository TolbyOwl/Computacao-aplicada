# Projeto Giovanna e Amigos - Sistema de Gestão Clínica

Este é um sistema full-stack desenvolvido para a gestão de atendimentos psicológicos e clínicos, unindo um front-end com um back-end robusto em **Flask (Python)** e banco de dados **Supabase**.

## 🏗️ Estrutura do Projeto

O repositório está dividido na estrutura de pastas do Flask:

- **`/static`**: arquivos de JavaScript e CSS.
- **`/templates`**: Páginas HTML. 

---

## 🚀 Guia de Inicialização

O repositório contém as bibliotecas para execução, então é necessário apenas inicializar o programa main.py e então acessar o endereço listado no console.
